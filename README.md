# -LegendOS-

This is a HTML based WebOS Setup which incorporates various sub-apps serving different functions:

- Notepad : For quickly scribbling down notes
- Calculator: For basic calculations
- Wallpaper: You can upload a custom image or select preset colours
- Terminal: Run a set list of commands: echo, help, clear, date, exit
- Tic Tac Toe: The classic game for local gameplay        

Tech Stack:

- HTML
- CSS 
- JS  
- Github Pages
- Only minimal AI use for javascript structuring
